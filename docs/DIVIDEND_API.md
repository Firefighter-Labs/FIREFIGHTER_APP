# 배당 데이터 정확도

## 우선순위 (자동)

| 순위 | 출처 | 정확도 | 설명 |
|------|------|--------|------|
| 1 | **Yahoo Finance** | ★★★ 실제 지급일 | 과거 실제 배당일·주당금액. 월/분기/주배당 **자동 판별** |
| 2 | FMP 유료 `dividends` | ★★★ | `VITE_FMP_PREMIUM=true` |
| 3 | Finnhub `stock/dividend` | ★★★ | 유료/플랜 제한 많음 |
| 4 | FMP `profile` 추정 | ★ | 연간 배당 ÷ 12 또는 ÷ 4 — **최후 수단** |
| 5 | 로컬 샘플 | ★ | API 전부 실패 시 |

**JEPI·JEPQ·일배당·주배당** 등은 티커 목록에 넣지 않아도, Yahoo 이력에서 주기를 자동 계산합니다.

## 개발 환경

`npm run dev` 시 Vite가 `/api/yahoo` → Yahoo Finance 로 프록시합니다.

## 배포 (Vercel 등)

루트 `vercel.json`에 Yahoo 프록시가 포함되어 있습니다. 다른 호스팅은 동일 경로로 리버스 프록시를 설정하세요.

## 환경 변수

```env
VITE_FMP_API_KEY=...        # 배당률·추정 fallback
VITE_FINNHUB_API_KEY=...    # 종목 검색
# VITE_FMP_PREMIUM=true     # FMP 정확 일정 (유료)
```

## 환율 (USD → KRW)

- **Frankfurter API** (`/api/fx` → `api.frankfurter.dev`) — 키 없이 USD/KRW 조회, **30분 캐시**
- 실패 시 마지막 캐시 또는 **1,350원** fallback
- 배당 탭 상단 **💱** 버튼으로 수동 새로고침

## 세금 표시 (간이)

| 시장 | 기본 | 감면 토글 ON (국내만) |
|------|------|----------------------|
| 국내 | 분리과세 **15.4%** | **9.9%** 가정 |
| 미국 | 원천징수 **15%** | — |

- UI: **세전(원본)** · **예상 수령(세후)** 동시 표기
- 생활비 커버·FIRE 커버율은 **세후** 기준
- ISA·종목별 실제 감면 요건·외국납부세액 공제는 **미구현** (참고용)

## 한계 (솔직히)

- **미래** 지급일은 공시/API에 따라 달라질 수 있음 → 과거 이력 기반 표시
- 추정 모드(`FMP 추정`)는 지급일이 맞지 않을 수 있음 → 배지 확인
- 환율·세금은 **간이 모델**이며 실제 수령액과 다를 수 있음
- 앱스토어 수준의 **법적 투자·세무 자문**이 아닌 개인 참고용
